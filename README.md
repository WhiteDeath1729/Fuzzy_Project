# Fuzzy_Project
High Performance Computer clusters consume significant energy when compute nodes remain idle. This project aims to develop a fuzzy logic-based resource management system that prioritises compute nodes for activation or shutdown based on their idle time, workload demand, and job waiting time.

Acknowledgements and Research Foundation
This project is inspired by the research paper:
Cocaña-Fernández, A., San José Guiote, E., Sánchez, L., & Ranilla, J. (2019). Eco-Efficient Resource Management in HPC Clusters through Computer Intelligence Techniques. Energies, 12(11), 2129.

Paper: https://doi.org/10.3390/en12112129

The paper proposes a two-stage approach to improving energy efficiency in High-Performance Computing (HPC) clusters, including fuzzy-system-based compute-node allocation.

This repository contains an independent implementation of selected concepts from the paper for educational and experimental purposes. The implementation, simplifications, design decisions, and experimental evaluations in this repository are my own, except where explicitly attributed otherwise.

This project is not the original implementation by the paper's authors and is not affiliated with them.
